## The Power of Absolute Control
**AbsoluteWindows** is not just a tool; it's your system's personal commander. Designed for elite users who demand efficiency, it condenses complex administrative tasks into a single, high-speed accessible interface. From deep-cleaning your system files to managing advanced environment variables, AbsoluteWindows provides pure, raw control at your fingertips, ensuring your PC remains lean, secure, and incredibly fast.

<br>

## What's New
• **Advanced Security:** Integrated Windows Defender and Microsoft Malicious Software Removal Tool (MSRT) for deep scans.  
• **One-Click Maintenance:** Automated Drive Optimization (TRIM/Defrag) and professional-grade RAM flushing.  
• **Deep Cleaning:** New modules to purge Windows Run history, system files, and recent history logs.

<br>

## Hot Keys
`Alt + Windows + W`  
Invoke the AbsoluteWindows Command Center from anywhere in Windows with the global master shortcut

`Alt + Windows + Z`  
Open Kill Not Responding Apps

## Adaptive Intelligence
<br>

The core of AbsoluteWindows is its **State-Aware Engine**. The menu intelligently monitors your PC and changes options dynamically based on your current status:

<br>

### 🌐 Network Connectivity
• **If Online:** Shows **"Disconnect Internet"**. One click instantly severs the connection for privacy or maintenance.  
• **If Offline:** Instantly transforms to **"Connect Internet"**, restoring your link in a split second.

<br>

### 🛡️ Security & UAC
• **If Active:** Shows **"Disable User Account Control"**. Quickly drops UAC to the lowest level for a seamless, prompt-free admin experience.  
• **If Silent:** Shows **"Enable User Account Control"**. Instantly restores default protection to guard your system.

<br>

## Feature Breakdown
<br>

### 🚀 Rescue & Performance
<br>

**Kill Not Responding Apps**  
Instantly terminates frozen applications that refuse to close normally.  
*Step-by-Step:* 1. Open menu. 2. Select "Kill Not Responding Apps". 3. The add-on clears the hang immediately.

<br>

**Restart Windows Explorer**  
Refreshes your desktop, taskbar, and file system without needing a full system reboot.  
*Step-by-Step:* 1. Select "Restart Windows Explorer". 2. Wait 1 second for the interface to reload.

<br>

**Clear Ram**  
Flushes the system standby list to recover memory for high-demand tasks.  
*Step-by-Step:* 1. Select "Clear Ram". 2. Experience immediate responsiveness in heavy applications.

<br>

### 🧹 Deep Cleaning Suite
<br>

**Clean System files & Temp**  
Safely removes junk files, temporary data, and system-level clutter that slows down your OS.  
*Step-by-Step:* 1. Navigate to the Clean category. 2. Choose "Clean System files" or "Clean Temp". 3. Confirm deletion to reclaim disk space.

<br>

**Empty Recycle Bin & Recent Logs**  
Wipes your trash and clears "Recent Files" and "Windows Run History" for total privacy.  
*Step-by-Step:* 1. Select "Empty Recycle Bin" or "Clean Windows Run History". 2. Your activity traces are purged instantly.

<br>

### 🛠️ Professional Tools
<br>

**Optimize and Defragment Drive**  
Triggers intelligent drive maintenance (TRIM for SSDs, Defrag for HDDs) to keep storage fast.  
*Step-by-Step:* 1. Select "Optimize and defragment drive". 2. Windows handles the background optimization automatically.

<br>

**Manage Services & Startup**  
Control which apps and services run in the background to ensure a lean boot sequence.  
*Step-by-Step:* 1. Select "Startup Manager" or "Manage Services". 2. Enable or disable items as required.

<br>

**Power Tools Access**  
Direct links to Cmd, Regedit and Environment Variables for administrative precision.  
*Step-by-Step:* 1. Choose your tool from the list. 2. It launches with full administrative privileges.
