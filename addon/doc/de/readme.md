> ### 🌐 Netzwerkkonnektivität
> * **Wenn online:** Zeigt **"Internet trennen"**. Ein Klick unterbricht sofort die Verbindung.
> * **Wenn offline:** Verwandelt sich in **"Internet verbinden"**, um die Verbindung wiederherzustellen.
